# Everdell — referencia de iconos y términos

**Uso**: equivalencias rápidas para las ayudas en Markdown  
**Alcance**: juego base  
**Validado**: 11/09/2026

Como los iconos del tablero y de las cartas no se reproducen aquí, se usan sus nombres en castellano.

---

## Recursos

| Nombre | Significado |
|---|---|
| **Ramita** | Recurso de madera; aparece en costes y recompensas |
| **Resina** | Recurso de construcción |
| **Piedra** | Recurso de construcción avanzada |
| **Baya** | Recurso usado habitualmente para jugar Bichos |
| **Cualquier recurso** | Elige ramita, resina, piedra o baya |

Los recursos no tienen límite de cantidad. Si se agotan las piezas, usa sustitutos.

---

## Cartas y puntos

| Término | Significado |
|---|---|
| **Carta** | Por defecto, carta superior del mazo |
| **Prado** | Ocho cartas boca arriba disponibles para todos |
| **Ficha de punto** | Punto obtenido durante la partida |
| **Puntos de final de partida** | Puntos que se calculan al terminar, según el texto |
| **Común** | Puede haber varias copias en una ciudad |
| **Única** | Solo una copia concreta por ciudad |
| **Ocupado** | Marca que una Construcción ya se usó para jugar gratis un Bicho |

## Colores de cartas

| Color | Nombre | Recordatorio |
|---|---|---|
| Marrón | Viajero | Se activa una vez al jugar |
| Verde | Producción | Al jugar y al preparar primavera/otoño |
| Roja | Destino | Se activa al colocar un trabajador |
| Azul | Gobierno | Bonificaciones y descuentos |
| Morada | Prosperidad | Bonus de puntuación final |

---

## Ubicaciones

| Término | Regla rápida |
|---|---|
| **Exclusiva** | Solo 1 trabajador |
| **Compartida** | Varios trabajadores |
| **Bosque** | Resuelve la carta; en 2-3 jugadores, 1 trabajador por carta |
| **Destino abierto** | Puede visitarlo un oponente |
| **Evento** | Requisito + pago; 1 jugador por Evento |
| **Refugio** | 2 cartas descartadas → 1 recurso |
| **Viaje** | Solo otoño; descarta cartas → puntos finales |

---

## Estaciones

| Estación | Beneficio al prepararte |
|---|---|
| Primavera | 1 trabajador + producción verde |
| Verano | 1 trabajador + hasta 2 cartas del Prado |
| Otoño | 2 trabajadores + producción verde |

Prepararse en verano no activa la producción verde.
