# Cartas de Lorcana

Consulta las cartas en [Lorcast](https://lorcast.com), donde puedes buscar por nombre, set y otras características.

En los artículos de esta guía, pulsa el nombre enlazado de una carta para abrir su imagen y leer el texto. Las imágenes se obtienen mediante la [API de Lorcast](https://lorcast.com/docs/api).

Esta guía se centra en explicar las reglas y las interacciones; el catálogo de cartas se consulta en Lorcast.
