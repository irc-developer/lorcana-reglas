## ❓ Duda

¿Qué objetos se pueden usar para representar las gotas de tinta? ¿Sirve un dado distinto de los que se usan para el daño? ¿Es obligatorio utilizar los contadores impresos de los sobres?

---

## ✅ Respuesta

**Sí, puedes usar un dado para representar tus gotas de tinta.** Las notas oficiales de Hyperia City permiten expresamente dados u otros objetos si no tienes los contadores impresos. CR 1.13.3 permite cualquier tipo de objeto que cumpla sus requisitos.

- Debe mostrar claramente la cantidad exacta de gotas que tienes.
- El mismo objeto no puede representar distintos tipos de contadores: dedica el dado a las gotas, sin usarlo también para indicar daño. Puedes usar otros dados para el daño. Un color o diseño diferente ayuda a distinguirlos; CR 1.13.3.2 no impone un color concreto ni prohíbe que ambos tipos se representen con dados.
- No puedes usar cartas estándar de Disney Lorcana como contadores. Los contadores impresos de gotas sí sirven: aunque tengan forma de carta, no son cartas estándar ni se mezclan con el mazo.

También sirven fichas u otros objetos que cumplan esas condiciones. Las gotas se colocan en el **pozo de tinta**, fuera de la zona de juego. La exigencia de caber dentro de una carta y no tapar toda su caja de texto corresponde a los contadores de daño, no a las gotas.

### En torneo

Las Tournament Rules efectivas el 14/07/2026, sección 5.2, todavía prohíben las representaciones numéricas en fichas salvo para el daño, sin incorporar expresamente las gotas introducidas por CR 2.3. **Confirma con el Lore Guide cómo representarlas en ese evento.** El permiso expreso de las reglas generales y de las notas del set no elimina esa falta de armonización en la política de torneo. Véase también [[Fichas de recordatorio sobre el mazo]].

---

## 🔄 Ejemplo

Tienes tres gotas y las representas con un dado dedicado a ellas en el pozo de tinta, mostrando **3**. Si retiras dos para pagar 2 {I} de un coste, cambias el dado a **1**. Cuando gastas la última, retiras el dado: las gotas se consumen, no se agotan como las cartas de tinta.
