## ❓ Duda

Un jugador olvida ganar el lore obligatorio de una localización en la Set Step y lo detecta tres o cuatro turnos después. ¿Puede recibir ahora todo el lore o debe rebobinarse?

---

## ✅ Respuesta

No se concede el lore retroactivamente. La acción obligatoria de la Set Step se omitió y, después de varios turnos, un rebobinado cruzaría decisiones e información nuevas; se deja el estado tal como está y se continúa. Un juez no puede añadir el lore en el turno actual como si la Set Step siguiera abierta. La llamada debe hacerse en cuanto se detecte el error para que el Lore Guide valore cualquier acción correctiva prevista para el evento.

## 🔄 Cómo se resuelve

1. Se comprueba que la Set Step y varios turnos ya terminaron.
2. Se determina que un rebobinado afectaría decisiones e información.
3. No se añade el lore ahora ni se reabre cada turno.
4. Se continúa y se registra la llamada según la política del evento.
