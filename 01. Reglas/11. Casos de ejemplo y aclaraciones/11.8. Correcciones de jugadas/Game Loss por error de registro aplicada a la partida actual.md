## ❓ Duda

En un match de dos partidas se descubre durante la segunda partida un Deck/Registration Error - Major. ¿Debe asignarse otra pérdida de partida a la primera partida, que también se jugó con el mazo discrepante?

---

## ✅ Respuesta

No. Un único error de mazo produce una única acción correctiva. La Game Loss se registra para la partida en curso (o para la siguiente si el jugador no está jugando cuando se dicta), nunca para una partida ya terminada. No se transforma retroactivamente en dos Game Loss ni en una Match Loss salvo que la infracción concreta tenga expresamente esa acción correctiva.

---

- [[Pérdida de partida (Game Loss)|Game Loss]]: la acción correctiva se aplica a una partida, no reescribe partidas terminadas.
- [[3.4 Error de mazo-registro mayor (Deck-Registration Error major)|DRE Major]]

---

## 🔄 Cómo se resuelve

1. Se confirma la discrepancia y la clasificación.
2. Se registra una única Game Loss para la partida en curso o la siguiente.
3. La partida anterior mantiene su resultado.
4. Se corrige el mazo o la lista según la investigación antes de continuar.
