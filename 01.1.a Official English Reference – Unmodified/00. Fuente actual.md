El original previo de la transición es `Documentacion Oficial/Comprehensive-Rules_2.2.0-EN.pdf`, CR 2.2.0, efectiva el 9 de julio de 2026. Se aplica hasta el 15 de octubre.

El original más reciente publicado es `Documentacion Oficial/CRUpdate_EN_Oct-2026.pdf`:

- **Version 2.3.0**.
- **Effective October 16, 2026**.
- **56 páginas**.

Hasta el 15 de octubre de 2026 la fuente normativa aplicable sigue siendo CR 2.2.0, efectiva el 9 de julio de 2026. Desde el 16 de octubre se aplica 2.3.0. El motor local selecciona el original correspondiente a la fecha; ambos PDF se conservan sin modificar.

Para leer el texto inglés, las reglas completas y el glosario, usa el MCP o el Markdown paginado del original aplicable: [[CRUpdate_EN_Oct-2026.paginas.md]] para 2.3.0 y [[Comprehensive-Rules_2.2.0-EN.paginas.md]] para 2.2.0. Cada encabezado indica la página del original. Los Markdown numerados de esta carpeta son transcripciones históricas incompletas. Acude al PDF cuando haga falta comprobar elementos visuales o una discrepancia de extracción.

El PDF 2.2 se conserva en `Documentacion Oficial/Comprehensive-Rules_2.2.0-EN.pdf` y el 2.1 en `CRUpdate_2.1.0_EN.pdf` para contrastes históricos.
